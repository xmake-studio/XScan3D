# XScan3D

Самодельный 3D-лидарный сканер. На валу шагового двигателя стоит 2D-лидар,
которым управляет плата на RP2040. Двигатель поворачивает лидар на пол-оборота,
и за это время лидар снимает всё пространство вокруг себя. В комплекте
приложение для Windows: оно запускает сканирование, само калибрует сканер,
объединяет несколько сканов в один и строит по точкам поверхность.

## Что понадобится

- собранный сканер XScan3D с прошивкой;
- USB-кабель от сканера к компьютеру;
- компьютер с Windows 10 или 11.

Программа и прошивка лежат на странице [Releases](../../releases):

| Файл | Что это |
| --- | --- |
| `XScan3D_<версия>_x64-setup.exe` | установщик приложения |
| `XScan3D-portable.exe` | то же приложение без установки: скачайте и запустите |
| `XScan3D-firmware.uf2` | прошивка для сканера |

## Первый запуск

### 1. Прошейте сканер

Нужно один раз и потом при каждом обновлении прошивки.

1. Отключите сканер от USB.
2. Зажмите кнопку **BOOTSEL** на плате и, не отпуская её, подключите USB-кабель.
3. На компьютере появится новый диск **RPI-RP2**. Кнопку можно отпустить.
4. Скопируйте на этот диск файл `XScan3D-firmware.uf2`.
5. Плата перезагрузится сама, а диск RPI-RP2 исчезнет. Прошивка установлена.

### 2. Установите приложение

Запустите `XScan3D_<версия>_x64-setup.exe` или просто откройте
`XScan3D-portable.exe`. Драйверы и дополнительные библиотеки не нужны.

### 3. Подключите сканер

Подключите сканер по USB и откройте приложение. Порт выбирать не нужно:
приложение находит сканер само по имени USB-устройства и не трогает другие
платы. Когда в нижней панели появится кнопка **«Начать скан»**, всё готово.

Калибровка сканера хранится в его собственной памяти, поэтому сканер можно
подключать к любому компьютеру: настройки поедут вместе с ним.

> Новый сканер стоит [откалибровать](#калибровка) сразу после первого скана.
> Без калибровки облако точек будет с заметными искажениями.

## Как сделать скан

1. **Установите сканер** на устойчивую ровную поверхность или штатив. Лидар
   должен видеть пространство вокруг, ничего не должно мешать ему вращаться.
   Кабель, идущий по валу, должен свободно закручиваться.
2. **Выберите длительность** ползунком в нижней панели, от 15 секунд до
   10 минут. Чем дольше скан, тем плотнее облако точек. Над ползунком
   показано примерное число точек (около 2300 в секунду) и уровень детализации:

   | Длительность | Уровень |
   | --- | --- |
   | до 45 с | Быстро |
   | до 2,5 мин | Стандарт |
   | до 7 мин | Подробно |
   | дольше | Максимум |

   По умолчанию стоит 3 минуты, это хороший выбор для комнаты.
3. **Нажмите «Начать скан»** (или `Ctrl+Enter`).
4. **Не мешайте сканеру.** Сначала он подготовится: доведёт платформу до
   упора, отойдёт на стартовую позицию и подождёт, пока затихнут колебания.
   Потом начнётся само сканирование. На экране видно, как облако набирается в
   реальном времени, а в панели показаны прогресс, оставшееся время и число
   точек.
5. Когда скан закончится, сканер издаст двухнотный сигнал, а приложение
   исправит искажения и сохранит скан в библиотеку. Ничего сохранять вручную
   не нужно.

**Остановить скан** можно кнопкой в нижней панели или сочетанием `Ctrl+Enter`.
Уже снятые точки сохранятся, скан будет помечен как «Прерван».

**Советы для хорошего результата:**

- Отойдите от сканера и не ходите рядом во время съёмки. Всё, что движется,
  оставит в облаке «призраков». Время на то, чтобы отойти, можно задать в
  **Настройки → Сканирование → Задержка перед стартом**.
- Не трогайте и не сдвигайте сканер, пока он работает.
- Зеркала, стёкла и очень тёмные блестящие поверхности лидар видит плохо:
  на их месте будут дыры или шум.
- Если сканер стоит на вибрирующей поверхности и облако выходит
  «размазанным», включите пошаговый режим (**Настройки → Сканирование →
  Режим → Пошаговый**). Он медленнее, зато сканер останавливается на каждом
  угле.
- Если кабель закрутился, нажмите **Настройки → Устройство → Размотать
  кабель**.

## Просмотр результата

Скан открывается в окне просмотра. Справа сверху находится панель
инструментов.

**Режимы камеры:**

- **Орбита** (по умолчанию). Перетаскивание мышью вращает, колесо
  приближает, правая кнопка мыши или перетаскивание с `Shift` сдвигают.
  Двойной клик по точке ставит её в центр вращения.
- **Полёт**, удобен внутри помещения. Мышь управляет обзором, `W` `A` `S` `D`
  перемещают, `E` или `Пробел` поднимают, `Q` или `Ctrl` опускают, `Shift`
  ускоряет, колесо мыши меняет скорость полёта.

**Другие кнопки:**

- **Показать всё** (или клавиша `F`) уместит весь скан в кадр.
- **Цвет** раскрашивает точки по высоте, по расстоянию до сканера, по сканам
  (удобно для объединённых) или оставляет их однотонными. Там же меняется
  размер точек и включается **срез сверху**: он скрывает всё выше заданной
  высоты, так что можно убрать потолок и заглянуть в комнату сверху.
- **Поверхность** переключает между облаком точек и поверхностью, построенной
  по нему (см. [Построение поверхности](#построение-поверхности)).
- **Экспорт** сохраняет результат в файл.

## Библиотека сканов

Слева находится список всех сканов. Он ведётся автоматически, примерно как
фотоальбом в телефоне.

- Клик открывает скан, `Ctrl`+клик выделяет несколько, `Ctrl+A` выделяет
  все, стрелки вверх и вниз переключают сканы.
- Правый клик открывает меню: **Переименовать** (или `F2`), **Экспорт**,
  **Показать в папке**, **Объединить**, **Калибровать по этому скану**,
  **Разъединить**, **Удалить** (или `Delete`). Удалённые файлы попадают в
  корзину Windows.
- Чужие файлы `.bin` и `.ply` можно перетащить прямо в окно или открыть
  через `Ctrl+O`.

Сканы хранятся в папке `Документы\XScan3D`. Папку можно поменять в
**Настройки → Основные → Папка со сканами**. Каждый скан сохраняется в виде
«сырых» данных со сканера, поэтому после новой калибровки все старые сканы
сами пересчитываются с исправленными параметрами.

Если приложение закрылось или пропало питание посреди скана, уже снятая
часть восстановится при следующем запуске.

## Объединение нескольких сканов

Одна точка съёмки не видит того, что спрятано за мебелью или за углом. Чтобы
получить всё помещение или несколько комнат, снимите его с разных мест и
объедините сканы.

1. Сделайте несколько сканов, переставляя сканер между ними. **Соседние
   сканы должны заметно перекрываться**, то есть видеть одни и те же стены и
   предметы.
2. Выделите в библиотеке два или больше сканов (`Ctrl`+клик).
3. Нажмите **«Объединить»**.
4. Приложение совместит сканы. Если оно не уверено в результате, оно
   покажет окно **«Проверьте совмещение»**: добавляемый скан будет подсвечен
   оранжевым. Посмотрите, совпадают ли стены, и нажмите **«Принять»** или
   **«Отклонить»**.

Объединённая группа появится в библиотеке как один элемент. К ней можно
потом добавить новые сканы: выделите группу вместе с новым сканом и снова
нажмите «Объединить». Разбить группу обратно можно командой
**«Разъединить»**.

Если совмещение не получается, подскажите приложению, как двигали сканер
(**Настройки → Объединение → Как двигали сканер**):

- **Как угодно**: приложение перебирает всё само (так стоит по умолчанию);
- **Почти на месте**: сканер сдвигали совсем немного;
- **С поворотом**: укажите примерный угол поворота между сканами.

Для съёмки на улице оставьте включённым **«Игнорировать растительность»**.
Тогда совмещение идёт по стенам и земле, а не по колышущейся листве.

## Построение поверхности

Облако точек можно превратить в сплошную поверхность, например для
3D-печати или для работы в CAD.

1. Откройте скан или объединённую группу.
2. Нажмите кнопку **Поверхность** на панели инструментов справа сверху.
3. В появившейся карточке нажмите **«Построить поверхность»**.
4. Подождите. Прогресс виден в карточке, обычно это занимает от нескольких
   секунд до минуты.
5. Готовая поверхность показывается вместо точек. Повторное нажатие кнопки
   **Поверхность** возвращает облако точек.

Если после этого скан изменился (например, к нему добавили ещё один при
объединении), появится надпись «Поверхность устарела». Нажмите
**«Перестроить»**.

Качество задаётся в **Настройки → Поверхность → Качество**: среднее, высокое
или максимум, то есть детализация 10, 5 или 2,5 мм. Чем выше качество, тем
дольше строится поверхность.

## Экспорт

Выделите скан и нажмите **Экспорт** на панели инструментов, `Ctrl+E` или
«Экспорт…» в контекстном меню. Можно сохранить:

| Что | Формат | Для чего |
| --- | --- | --- |
| Облако точек | PLY | CloudCompare, MeshLab, Blender. Цвета будут как на экране |
| Поверхность | PLY, OBJ или STL | 3D-печать, CAD, 3D-редакторы |
| Исходные данные | BIN | поток сканера как есть, его можно пересчитать с другой калибровкой |

Все координаты сохраняются в миллиметрах.

## Калибровка

Сканер собран вручную, поэтому лидар всегда стоит на валу чуть-чуть неровно.
Калибровка измеряет эти отклонения и убирает искажения: раздвоенные стены,
«шов» на облаке и концентрические кольца на потолке. Делать её нужно один раз
после сборки и повторять, если лидар снимали или переставляли.

1. Поставьте сканер посреди **обычной комнаты** с ровными стенами, полом и
   потолком.
2. Сделайте скан с настройками по умолчанию. Сектор поворота должен быть
   **Авто**, длительность от 3 минут.
3. Правым кликом по этому скану выберите **«Калибровать по этому скану»**.
   Можно и так: **Настройки → Калибровка → Калибровать по выбранному скану**.
4. Дождитесь окончания. Приложение покажет таблицу ошибок «Сейчас» и
   «Подобрано» в миллиметрах (меньше значит лучше).
5. Если стало лучше, нажмите **«Применить»**.

Калибровка записывается в память сканера. Если в этот момент сканер не
подключён, она запишется при следующем подключении. Все сохранённые сканы
сразу пересчитываются с новой калибровкой.

Коррекция микрошага двигателя (убирает «волны» на стенах) отдельно делать не
нужно: она вычисляется по каждому скану автоматически.

## Настройки

Настройки открываются кнопкой с шестерёнкой в верхней панели окна или
сочетанием `Ctrl+,`.
Самое полезное:

| Раздел | Что там |
| --- | --- |
| Основные | язык, светлое или тёмное оформление, папка со сканами |
| Сканирование | задержка перед стартом, режим (непрерывный или пошаговый), сектор поворота |
| Отображение | цвет и размер точек, объёмное затенение, сетка пола, максимальная дальность |
| Калибровка | результат калибровки и ручная правка параметров крепления лидара |
| Объединение | как двигали сканер, детализация, игнорирование растительности |
| Поверхность | включение функции, качество, обрезка и сглаживание |
| Устройство | состояние подключения, ручной выбор порта, обслуживание сканера, журнал |

В разделе **Устройство → Обслуживание** есть:

- **Размотать кабель**: сканер повернётся на четверть оборота, чтобы
  раскрутить кабель;
- **Текущее положение — ноль**: считать текущий угол платформы нулевым;
- **Звуковой сигнал**: проверить, что сканер отвечает;
- **Журнал устройства**: сообщения прошивки на случай проблем.

## Индикатор и звуки сканера

| Цвет светодиода | Что значит |
| --- | --- |
| Фиолетовый | сканер загружается |
| Зелёный | готов к работе, двигатель обесточен |
| Красный | двигатель под током: идёт скан или платформа движется |

Красный лазер-указатель горит всё время, пока сканер включён.

В начале каждого скана платформа доходит до механического упора, и двигатель
может коротко «потрещать» об него. Это нормально: так сканер находит точный
ноль. По окончании скана двигатель проигрывает короткую мелодию из двух нот.

Между сканами двигатель обесточивается, чтобы не грелся, и вал можно
повернуть рукой. На точность это не влияет: следующий скан всё равно начнётся
с поиска упора.

## Если что-то не работает

**Приложение пишет «Поиск сканера…» и не находит его**

- Проверьте кабель: некоторые USB-кабели умеют только заряжать и не передают
  данные.
- Убедитесь, что сканер прошит именно прошивкой XScan3D. Плата с другой
  прошивкой определяется как «Pico» и игнорируется.
- Попробуйте подключить сканер вручную: **Настройки → Устройство →
  Подключить вручную**, выберите порт и нажмите «Подключить».

**«Сканер молчит»**

- Переподключите USB-кабель.
- Проверьте, что в **Настройки → Устройство** включён **Сигнал DTR**. Без
  него USB-порт RP2040 не передаёт данные.

**Облако двоится, на потолке видны кольца, по облаку идёт «шов»**

Сканер не откалиброван или калибровка устарела. Выполните
[калибровку](#калибровка).

**Облако размытое, «дрожит»**

Сканер стоит на неустойчивой поверхности. Поставьте его на что-то
потяжелее или включите пошаговый режим.

**Сканы не совмещаются при объединении**

У них слишком мало общего. Снимите промежуточный скан между ними или
подскажите приложению, как двигали сканер (см.
[Объединение](#объединение-нескольких-сканов)).

**Скан обрывается, «Связь со сканером потеряна»**

Проверьте, не задевает ли что-нибудь кабель при вращении, и не
переключается ли компьютер в спящий режим. Подключите сканер к другому
USB-порту, лучше напрямую, а не через хаб.

## Для разработчиков

```
src/                 прошивка (PlatformIO, Arduino-ядро для RP2040)
app/                 приложение (Tauri: ядро на Rust + интерфейс на Svelte), см. app/README.md
tools/               эталонные Python-скрипты, с которыми сверяется ядро приложения
tools/lidar_bridge/  отладочная прошивка: передаёт сырые байты лидара по USB
```

### Сборка

Прошивка:

```bash
pio run -e pico
pio run -e pico -t upload --upload-port <порт>
```

Приложение описано в [app/README.md](app/README.md) (на английском).

### Выпуск версии

Создайте и отправьте тег версии. GitHub Actions соберёт прошивку и
приложение и опубликует релиз с обоими файлами:

```bash
git tag v1.0.0
git push origin v1.0.0
```

Тег с суффиксом (`v1.1.0-beta.1`) публикуется как пре-релиз.
